# Требования к продукту

## Основная идея

Приложение для совместных списков любого типа. Ключевая механика: каждый участник группы «берёт на себя» пункт — остальные видят в реальном времени кто что делает/несёт/покупает.

## Типы списков

| Тип | Пример |
|-----|--------|
| Список покупок | Поход в магазин всей семьёй |
| Список вещей в поездку | Кто что берёт на море / в горы / на дачу |
| Подготовка к мероприятию | Кто что готовит на день рождения |
| Переезд | Кто что пакует и везёт |
| Пикник / поход | Распределение снаряжения и еды |

## Функциональные требования

### MVP

#### Авторизация
- Вход через Google
- Вход через Apple (iOS)
- Вход через номер телефона

#### Списки
- Создать список (название, опциональный тип)
- Редактировать название списка
- Удалить список
- Просмотр всех своих списков

#### Пункты списка
- Добавить пункт (название, опциональное количество)
- Редактировать пункт
- Удалить пункт
- «Взять на себя» пункт — имя пользователя прикрепляется к пункту
- Отметить пункт выполненным (✅)
- Снять отметку

#### Совместный доступ
- Пригласить участника по ссылке
- Участник видит список и всех участников
- Real-time синхронизация всех изменений

#### Уведомления
- Push при добавлении нового пункта
- Push когда участник отметил пункт выполненным

### После MVP

- Шаблоны списков (готовые наборы пунктов по типу)
- История изменений
- Статистика (кто сколько пунктов выполнил)
- Архив завершённых списков
- Комментарии к пунктам

## Нефункциональные требования

- Работа offline: чтение кэшированных данных, запись в очередь
- Real-time синхронизация при наличии сети (< 1 сек задержка)
- Поддержка iOS 16+ и Android 8+ (API 26+)
- Локализация: русский (основной), английский
