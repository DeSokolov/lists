# Architecture Decision Records

Здесь хранятся важные архитектурные решения.

## Формат файла

`NNNN-короткое-название.md`

## Шаблон

```markdown
# NNNN — Название решения

## Статус
Принято / Отклонено / Устарело

## Контекст
Что за проблема и почему нужно решение.

## Решение
Что именно решили сделать.

## Последствия
Плюсы и минусы принятого решения.
```
