# 005 — Экран деталей списка

**Статус:** ✅ Готово

## Описание
Экран работы с конкретным списком: просмотр, добавление пунктов, управление статусами.

## Что сделано
- Отображение пунктов списка с чекбоксами
- **Взять** — закрепить пункт за собой (имя видно всем участникам: «Маша берёт зарядку»)
- **Снять** — отказаться от взятого пункта
- **Выполнить** — отметить пункт как сделанный (чекбокс, у всех появляется ✓)
- Добавление пункта через FAB → диалог с названием и количеством
