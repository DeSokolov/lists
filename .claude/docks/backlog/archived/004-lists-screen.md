# 004 — Экран списков

**Статус:** ✅ Готово

## Описание
Главный экран приложения со всеми списками пользователя.

## Что сделано
- Отображение всех списков пользователя в виде карточек
- Создание нового списка через FAB → диалог
- Выбор типа списка при создании (SHOPPING, TRAVEL, EVENT, MOVING, GENERAL)
- Переход в экран деталей по нажатию на карточку
