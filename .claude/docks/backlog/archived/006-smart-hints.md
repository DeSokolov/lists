# 006 — Умные подсказки

**Статус:** ✅ Готово

## Описание
Автодополнение при добавлении пункта, адаптированное под тип списка.

## Что сделано
- Подсказки фильтруются по `ListType` (SHOPPING, TRAVEL, EVENT, MOVING, GENERAL)
- Фильтрация по тексту, который печатает пользователь
- Не нужно каждый раз печатать «молоко», «зарядка» и т.д.
