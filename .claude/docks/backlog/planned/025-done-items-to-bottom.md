# 025 — Выполненные пункты уезжают вниз

**Статус:** 🔲 Backlog  
**Приоритет:** 🟡 Средний

## Описание

Когда пользователь отмечает пункт списка выполненным (чекбокс), этот пункт плавно анимированно перемещается в конец списка. Выполненные пункты остаются видимыми (отмечены галочкой, текст зачёркнут) и группируются внизу отдельным блоком. Снятие галочки возвращает пункт в активную часть списка.

## Что нужно сделать

- [ ] **UiState / Presentation** — добавить вычисляемый порядок в `displayItems`: сортировать так, что `isDone == false` идут первыми, `isDone == true` — после; сортировка стабильная (relative order внутри каждой группы сохраняется)
- [ ] **ListDetailScreen** — заменить текущий `derivedStateOf` для `displayItems`: добавить `sortedBy { it.isDone }` в цепочку после фильтров; убедиться, что `key = { it.id }` у `LazyColumn items` уже выставлен (есть — хорошо)
- [ ] **Анимация перемещения** — включить `animateItem()` (Compose Multiplatform 1.7+) на элементе внутри `LazyColumn`: добавить `Modifier.animateItem()` к корневому `Column` внутри `SwipeToDismissBox`
- [ ] **Визуальный разделитель** — опционально: добавить `item { }` с заголовком «Выполнено (N)» между активными и выполненными пунктами; показывать только когда выполненных ≥ 1
- [ ] **ItemRow** — опционально: добавить `Modifier.alpha(if (item.isDone) 0.5f else 1f)` для визуального разграничения выполненных строк
- [ ] **Тест** — проверить, что `displayItems` для смешанного набора возвращает невыполненные перед выполненными при всех комбинациях фильтров (`filterMine`, `searchQuery`)

## Архитектурные заметки

### Где менять

| Файл | Что изменить |
|------|-------------|
| `ui/detail/ListDetailScreen.kt` | В `derivedStateOf { ... }` для `displayItems` добавить `.sortedBy { it.isDone }` последним в цепочке |
| `ui/detail/ListDetailScreen.kt` | На корневом `Column` внутри `SwipeToDismissBox` добавить `Modifier.animateItem()` |
| `ui/detail/ListDetailScreen.kt` | (Опционально) разбить на два блока с заголовком `item { }` между ними |
| `ui/detail/ItemRow.kt` | (Опционально) добавить `Modifier.alpha(...)` для приглушения выполненных строк |

### Почему в UI, а не в ViewModel

Сортировка для отображения — presentation-логика представления, не бизнес-логика. `ViewModel` отдаёт `items` в порядке репозитория. Сортировка для визуальной группировки — ответственность `derivedStateOf` в UI-слое, аналогично существующим фильтрам `filterMine` и `searchQuery`.

### Ключ анимации

`LazyColumn` уже использует `key = { it.id }` — обязательное условие для корректного `animateItem()`. Дополнительных изменений не требуется.
