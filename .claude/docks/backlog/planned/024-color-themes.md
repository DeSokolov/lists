# 024 — Цветовые темы

**Статус:** 🔲 Backlog  
**Приоритет:** 🟡 Средний

## Описание
Возможность переключать цветовую тему приложения. Пользователь выбирает один из трёх вариантов оформления — настройка сохраняется между запусками.

## Темы

| Тема | Описание |
|------|----------|
| ⚪ Белая | Текущий стиль — светлый лавандово-белый фон, индиго акцент |
| ⚫ Чёрная | Тёмная тема — тёмный фон, светлый текст |
| 🩷 Розовая | Розово-персиковая палитра, тёплые оттенки |
