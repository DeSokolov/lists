# Lists App — Идея проекта

## Концепция

Мобильное приложение для **совместных списков любого типа** — покупки, вещи в поездку, подготовка к мероприятию и всё что угодно. Ключевая фишка — каждый участник видит кто что взял/сделал в реальном времени.

Вдохновение: **Купи Батон** — но значительно шире по охвату сценариев.

---

## Уникальное торговое предложение

Существующие приложения решают только часть задачи:
- **Bring!, Купи Батон** — только списки покупок
- **Packr, PackPoint** — только список вещей в поездку, без нормальной совместной работы
- **SingularityApp, TickTick** — таск-менеджеры, слишком сложные для бытового использования

**Наша идея** — простое приложение, где:
- Можно создать список любого типа
- Поделиться с группой людей по ссылке
- Каждый отмечает **свои** пункты («Маша берёт зарядку»)
- Все видят статус в реальном времени
- Умные подсказки по типу списка — не нужно печатать «молоко» каждый раз

## Типы списков

| Тип | Пример использования |
|-----|----------------------|
| SHOPPING — Список покупок | Обычный поход в магазин всей семьёй |
| TRAVEL — Список вещей в поездку | Кто что берёт на море / в горы / на дачу |
| EVENT — Подготовка к мероприятию | Кто что готовит на день рождения |
| MOVING — Переезд | Кто что пакует и везёт |
| GENERAL — Общий | Любые задачи и напоминания |

---

## Ключевая механика — «Кто что берёт»

1. Создаётся общий список с пунктами
2. Участник **«берёт на себя»** пункт — все видят «Маша берёт зарядку»
3. Если передумал — снимает пункт с себя (кнопка «Снять»)
4. Отметил как взятое/куплено — у всех появляется ✓
5. Push-уведомление если кто-то добавил новый пункт в совместный список

## Реализованные фичи (текущий статус)

### Экран списков
- Отображение всех списков пользователя
- Создание нового списка (FAB → диалог)
- Тип списка влияет на умные подсказки

### Экран деталей списка
- Пункты списка с чекбоксами
- Кнопка «Взять» — закрепить пункт за собой; имя видно всем участникам
- Кнопка «Снять» — отказаться от взятого пункта
- Добавление пункта (FAB → диалог с названием и количеством)
- **Умные подсказки** при добавлении пункта — фильтруются по типу списка и по тому, что уже печатает пользователь
- **Поиск** — иконка в TopAppBar; поисковое поле заменяет заголовок, фильтрует пункты по названию
- **Фильтр «Все / Мои»** — чипы под TopAppBar; «Мои» показывает только взятые текущим пользователем
- **Удаление свайпом** — свайп влево открывает красный фон с иконкой корзины
- **Поделиться** — иконка Share копирует ссылку `lists://join/{listId}` в буфер, Snackbar подтверждает
- **Участники** — меню ⋮ → «Участники» показывает BottomSheet со всеми, кто что-то взял
- **Уведомления** — меню ⋮ → «Уведомления: вкл/выкл» (UI готов; реальный push — после подключения Firebase)

## Технический стек

| Компонент | Технология |
|-----------|------------|
| Mobile UI | Compose Multiplatform (KMP) — iOS + Android из одной кодовой базы |
| Язык | Kotlin |
| Архитектура | Clean Architecture: UI → Presentation (ViewModel) → Domain (UseCase) → Data (Repository) |
| DI | Koin 4.0.0 |
| БД локально | Room (KMP) 2.7.0 — запланировано |
| Backend / Sync | Firebase Firestore — реальный; сейчас stub-реализация (USE_STUBS = true) |
| Auth | Firebase Auth — stub; реальный после добавления GoogleService-Info.plist |
| Push | Firebase Cloud Messaging — после подключения Firebase |
| Монетизация | RevenueCat — запланировано |
| Аналитика | Firebase Analytics |
| Ошибки | Firebase Crashlytics |
| Сборка iOS | fastlane match + xcodegen |
| Сборка Android | Gradle + fastlane supply |
