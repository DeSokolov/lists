021 — Шаблоны списков

Готовые наборы пунктов при создании нового списка. Типы уже есть (SHOPPING, TRAVEL, EVENT, MOVING), нужно добавить данные и UI выбора.

Плюсы

  • ~3–5 часов работы
  • Всё в одном месте (диалог создания)
  • ListType уже реализован
  • Нет новых экранов

Минусы

  • Меньше UX-ценности до публикации
  • Premium-функция — нужен RevenueCat позже
B

018 — Онбординг

2–3 слайда при первом запуске: объясняет механику «Кто что берёт», кнопка «Пропустить», переход к спискам.

Плюсы

  • Высокая UX-ценность
  • Нужен перед публикацией
  • Чистая Compose UI задача
  • Со stubs работает полностью

Минусы

  • ~4–6 часов (новые экраны + анимации)
  • Нужен первый запуск через DataStore
Рекомендация агента

Начать с 021 — Шаблоны: минимум времени, расширяет уже рабочий флоу создания списка, виден результат сразу.
