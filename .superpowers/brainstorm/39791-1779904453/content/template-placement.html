Где выбирать шаблон?

Как шаблоны встраиваются в существующий флоу создания списка

A

Внутри диалога создания

После выбора типа списка — появляется секция «Начать с шаблона». Всё в одном диалоге.

Диалог «Новый список»
Начать с шаблона

Плюсы

  • Нет новых экранов
  • Быстрый флоу

Минусы

  • Диалог становится длиннее
B

BottomSheet после создания

Список создаётся пустым, затем сразу появляется BottomSheet: «Добавить из шаблона?»

Экран деталей → BottomSheet
Список пуст
Начать с шаблона?

Плюсы

  • Диалог не меняется
  • Шаблоны видны развёрнуто

Минусы

  • Дополнительный шаг
C

Кнопка «+ Из шаблона» в списке

В пустом списке — два FAB или кнопка «Из шаблона» рядом с «Добавить пункт».

Экран деталей (пустой список)
Список пока пуст

Плюсы

  • Можно добавить в любой момент
  • Не навязывает шаблон

Минусы

  • Менее заметно
  • Сложнее найти
Рекомендация

A — быстрее реализовать, нет новых экранов, естественный флоу: выбрал тип → сразу видишь подходящие шаблоны.
